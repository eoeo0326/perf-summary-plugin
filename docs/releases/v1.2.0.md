Claude Code와 Codex에서 같은 성과 요약 스킬을 사용할 수 있습니다. `npx skills`로 설치하면 별도 MCP 등록 없이 GitHub PR 활동을 수집하고 한국어 Markdown 보고서를 작성합니다.

## 달라진 사용 경험

- **스킬만 설치하면 실행할 수 있습니다.** Node.js 실행 번들·보고서 지침·라이선스를 함께 제공해 별도 빌드나 npm 의존성 설치가 필요 없습니다.
- **연간·월간·기간별 보고서를 모두 지원합니다.** 조직·레포·계정 필터, 미리보기, 출력 경로를 공통 CLI로 처리합니다.
- **긴 수집 작업을 이어서 조회할 수 있습니다.** 로컬 작업 프로세스가 수집을 진행하고 진행 상태·취소·PR 근거 페이지를 제공합니다. HTTP 포트나 상시 실행할 서버는 필요 없습니다.
- **기존 MCP도 계속 사용할 수 있습니다.** 스킬 CLI와 MCP가 같은 입력 검증·집계 로직을 공유합니다.
- **Windows 생성물 검사를 수정했습니다.** 라이선스 줄바꿈 차이로 검증이 실패하던 문제를 해결했습니다.

## 설치 및 업데이트

### 공통 스킬

현재 프로젝트의 Claude Code와 Codex에 설치합니다.

```bash
npx skills add eoeo0326/perf-summary-plugin@v1.2.0 --skill perf-summary -a claude-code -a codex
```

모든 프로젝트에서 사용하려면 `-g`를 추가합니다. 기존 스킬은 `npx skills update`로 업데이트할 수 있습니다.

Claude Code에서는 `/perf-summary`, Codex에서는 `$perf-summary`를 호출합니다.

```text
/perf-summary --year 2025 --org acme
$perf-summary --month 2026-09 --repo acme/app
$perf-summary --since 2026-01 --until 2026-09 --account alice,bob --dry-run
```

### 기존 MCP·플러그인 사용자

기존 플러그인은 업데이트하면 공통 CLI 실행 지침을 사용합니다. 동일한 스킬을 중복 설치할 필요는 없습니다.

MCP만 사용하는 경우 기존 등록의 실행 인자를 다음 고정 버전 URL로 갱신합니다.

```bash
npx -y https://registry.npmjs.org/perf-summary-mcp/-/perf-summary-mcp-1.2.0.tgz
```

스킬 방식에는 MCP 등록이 필요 없습니다. MCP 패키지는 기존 클라이언트와의 호환을 위해 계속 배포합니다.

## 실행 환경과 호환성

- Node.js 22 이상과 최신 GitHub CLI, 조회할 계정의 `gh auth login`이 필요합니다. 별도 LLM API 키는 필요 없습니다.
- 집계는 실행 PC 시간대의 **PR 생성일**을 기준으로 합니다. 직접 push한 커밋은 포함하지 않습니다.
- 기본 저장 위치는 사용자 작업 폴더 아래 `PerformanceSummary`입니다. 미리보기는 파일을 쓰지 않고 기존 파일은 명시적으로 허용할 때만 덮어씁니다.
- 수집 결과와 GitHub 토큰은 메모리에만 보관합니다. 프로세스 종료 후에는 재수집해야 하며 로컬 작업 프로세스는 1시간 유휴 후 종료합니다.

- macOS·Linux·Windows에서 Node.js 22·24 조합의 CI를 통과했습니다.
